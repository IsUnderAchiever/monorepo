About This Project

A classic multi-page website — no SPA, no router, just .html files linked together with <a href>.

How Navigation Works

There is no router library. Each page is a standalone HTML file:

FileURLWhat it does
index.html / Home page with counter demo
about.html /about.html This page — project info

Navigation between pages is a standard <a href="about.html"> — the browser loads a full new page. Vite's dev server handles serving any .html file in the project root automatically.

Tech Choices

🧩 jQuery

DOM manipulation and event handling. Imported as an ES module via Vite from node_modules.

🎨 Bootstrap 5

CSS framework and JS components. Bootstrap 5 removed its jQuery dependency — we add jQuery separately.

⚡ Vite+

Dev server with HMR and production bundler. Replaces the need for a separate "live-server" or manual reload.

📦 pnpm Workspace

Monorepo package management. catalog: references ensure consistent dependency versions across projects.
